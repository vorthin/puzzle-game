# 宝贝益智乐园 🧩

面向 **3-6 岁儿童**的益智游戏平台。纯 HTML + CSS + JavaScript，**零依赖、零构建、纯离线**——双击 `index.html` 即可运行，电视 / 平板 / 手机浏览器均可。

## ✨ 特性

- **零安装**：一个静态文件夹，拷到任何设备用浏览器打开就能玩
- **语音引导**：中文语音朗读题目（浏览器 `speechSynthesis`），不识字也能玩
- **永不惩罚**：答错只有温柔提示音，没有叉号、扣分和失败画面
- **自适应难度**：连对 3 次升档、连错 2 次降档，永远不会"失败"
- **贴纸收集**：通关发贴纸，首页贴纸墙展示成就（有限、有仪式感，不发无限货币）
- **家长门**：设置需算对一道加法题才能进入，可管理防沉迷时长、游戏开关
- **无需素材**：全部 emoji + CSS 动画，仓库里没有一张图片

## 🚀 运行方式

```bash
# 最简单：双击 index.html
# 或起一个本地静态服务器：
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## ☁️ 部署

无构建步骤，任意静态托管均可（GitHub Pages / Cloudflare Pages / Vercel / Nginx）。

本项目部署在 **Cloudflare Pages**：推送即自动部署，免费 CDN + HTTPS。

## 🏗️ 架构

```
js/
├── engine/          引擎层（游戏无关的通用能力）
│   ├── AudioManager.js   合成音效，无需音频文件
│   ├── SpeechManager.js  中文语音朗读 + onEnd 回调兜底
│   ├── TimerManager.js   防沉迷计时
│   ├── RewardManager.js  星星 / 彩带 / 夸奖
│   ├── Store.js          命名空间存档（难度 / 贴纸 / 今日时长）
│   └── GameManager.js    ★ 游戏注册中心 + api.rounds() 多关卡循环
└── games/           游戏模块，新增一个文件 + index.html 加一行即上线
```
