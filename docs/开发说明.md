# 宝贝益智乐园 —— 项目说明

3-6 岁儿童益智游戏平台。纯离线，双击 `index.html` 即可运行（电视 / 平板 / 手机浏览器都行）。

## 三个高频操作

### ① 加一个新游戏
1. 在 `js/games/` 新建 `my-game.js`，照下面模板写
2. 在 `index.html` 的「游戏模块」区加一行：
   `<script src="js/games/my-game.js"></script>`
3. 刷新页面——首页自动多出一张卡片，不用改别的

### ② 删一个游戏
删掉 `js/games/xxx.js` 文件，并删掉 `index.html` 里对应那一行 `<script>`。其他游戏不受影响。

### ③ 临时关闭游戏（不删代码）
进游戏 → 右上角 ⚙️ → 家长验证（算一道加法）→ 在「开启/关闭游戏」里关掉开关。

## 首页布局

首页会根据屏幕尺寸自动排列游戏卡片：

- 宽屏默认 4 列；新增第 9 个游戏后会有第三行，必要时可滚动；
- 宽度不超过 `700px` 时使用 3 列，手机上的点击目标不会被压得太小；
- 矮的横屏设备使用紧凑的 4 列布局；
- `.grid` 有滚动兜底；9 个游戏在矮屏可能需要滚动，避免缩小其他 8 张卡片的点击面积。

新增游戏时不需要手动改列数；只需检查卡片标题在目标设备上是否仍然清楚。

## 小小社区帮手：步行 RPG 试玩

`js/games/community-helper.js` 定义 12×8 地图、碰撞、人物/道具、寻路、两条任务和停止逻辑；
`css/community-helper.css` 定义社区地图、走路动画和窄屏虚拟方向盘。

- 方向键或遥控器走动（长按连续走）；手机可按方向盘；点地图上的目标会沿可走的路自动过去。靠近目标后点「交谈 / 使用」或按空格、Enter。
- 小园丁：跟小兔说话 → 观察花的泥土（也可以先找水壶）→ 浇水 → 回访小兔。练观察和因果。
- 小邮递员：跟邮递员说话 → 取包裹 → 对照 ⭐ / 🔵 门牌 → 正确投递 → 回访。练听线索、分辨图形与空间寻路。
- 遥控器在剧情选项出现时用左右切换选项、Enter 确认；线索忘了可点「再听一次」。退出时游戏的 `stop()` 必须解绑全局键盘监听并停掉移动计时器。

故事是探索和分支，不套线性 `api.rounds()`。完成任务单独发社区贴纸，贴纸落在 `ch_stickers`，与 `lg_` 等旧存档隔离。场景当前用 emoji + CSS 快速验证走动玩法，尚无专门美术资源；设备不支持中文语音时需要家长伴读。

## 光之小卫士：关卡设计

《光之小卫士》保留三个入口，但每个入口内部是一个短任务循环：

- `变身配对`：难度 1/2/3 依次净化 2/2/3 波，每波重新打乱能量兽；
- `光线数数`：每局有 3/4/5 个小任务，高难度交替加入左右更多/一样多比较；
- `能量灯呼吸`：每局完成 3/4/5 轮，吸气和呼气各保持舒适的 2.6 秒，完成一轮点亮一颗星星。

关卡定义在 `js/games/light-guardian/levels.js`，文字提示和呼吸节奏在
`config.js` 的 `levelInfo` 里。语音清单在 `config.js` 的 `voice.clips`：录音存在时优先播放录音，
当前无 `assets/voice/` 素材时由 `VoiceManager` 朗读中文指令，不支持朗读才播放提示音。
新增延迟动画时必须通过 `alive(stage)` 或保存会话令牌判断，因为用户可能在动画中按返回离开；
平台的 `app.js` 会调用游戏的 `stop()` 清理计时和音频，游戏内回首页/结束也会卸载游玩舞台。

这样丰富玩法的原则是「增加变化，不增加入口」：低龄孩子仍然只需认识三个图标，
但每次进入关卡会遇到不同的波次、数量、比较关系和进度目标。

## 新游戏模板

```javascript
GameManager.register({
  id: 'my-game',          // 唯一，别和别人重复
  name: '我的游戏',        // 首页卡片文字
  icon: '🎮',              // 首页卡片图标
  color: 'linear-gradient(135deg,#a1c4fd,#6a9dfd)', // 卡片背景
  age: [3, 6],            // 适合年龄，家长选了年龄会自动过滤
  title: '这是玩法提示',   // 进游戏后顶部标题

  // stage: 游戏画布容器（DOM），已清空，往里塞东西就行
  // api:   引擎给你的工具，见下
  start(stage, api) {
    const btn = api.util.el('button', 'habit-btn', '点我');
    btn.onclick = () => api.reward('太棒了！');   // 答对 → 奖励
    stage.appendChild(btn);
    api.speak('这是语音提示');
  }
});
```

### 模板二：多关卡（推荐，单次能玩 3-5 分钟）

单题游戏玩两下就结束了。用 `api.rounds()` 就能变成「一局好几关」：

```javascript
const STICKERS = [                       // 贴纸册放 start() 外面
  { id: 'g1', emoji: '⭐', name: '星星' },
  { id: 'g2', emoji: '🌈', name: '彩虹' },
];
// 注册到首页贴纸墙，要放在 start() 外面：孩子第一次点进来之前就该看到
Store.wall.register({
  id: 'my-game', title: '我的游戏', items: STICKERS,
  owned: () => Store.create('my_').getStickers(),
});

GameManager.register({
  id: 'my-game', name: '我的游戏', icon: '🎮',
  color: 'linear-gradient(135deg,#a1c4fd,#6a9dfd)',
  age: [3, 6], title: '找一找',

  start(stage, api) {
    const r = api.rounds(stage, {
      total: 5,             // 本次玩几关
      scope: 'my',          // 存档命名空间（难度/贴纸记在这）
      stickers: STICKERS,   // 通关时自动发一张
      draw: buildOne,       // 画第 no 关（no 从 1 开始）
      onWin(res) {          // 全部通关，res = { sticker, isNew }
        api.setTitle(res.isNew ? '拿到新贴纸啦！' : '全部成功！');
      },
    });

    function buildOne(host, no) {
      const btn = api.util.el('div', 'habit-btn', '点我');
      btn.onclick = () => r.next();          // 答对
      host.appendChild(btn);
      // 难度：连对 3 次升一档，连错 2 次降一档，永不降到 min 以下
      const lv = r.store.getLevel();
    }
  },
});
```

## api 提供的能力

| 用法 | 说明 |
|------|------|
| `api.speak('文字')` | 中文语音朗读 |
| `api.speak('文字', fn)` | 念完后回调 `fn`（**部分设备不触发 onend，引擎有超时兜底，一定会调**） |
| `api.canSpeak()` | 这台设备能不能朗读语音。不能的话游戏应该降级成看图版 |
| `api.sound.good()` | 答对音效 |
| `api.sound.soft()` | 答错的温柔提示音（不刺耳） |
| `api.reward('夸奖语')` | 弹星星+彩带+语音，参数可省略 |
| `api.setTitle('新标题')` | 动态改顶部标题 |
| `api.rounds({...})` | 多关卡循环，见上面的模板二 |
| `api.store` | `Store` 本体，游戏可自己 `api.store.create('xx_')` |
| `api.util.shuffle(数组)` | 打乱数组 |
| `api.util.pick(数组)` | 随机取一个 |
| `api.util.randInt(n)` | 0~n-1 随机整数 |
| `api.util.el(标签,类名,文字)` | 快速创建元素 |
| `api.makeDraggable(元素,{onMove,onDrop})` | 让元素可拖拽 |
| `api.exit()` | 退回平台首页 |

## Store：存档怎么存

```javascript
const s = Store.create('xx_');   // 'xx_' 是前缀，不同游戏互不覆盖

s.get('k', 默认值);  s.set('k', 值);  s.del('k');

// 难度（连对升 / 连错降，永远不会出现「失败」）
s.getLevel();  s.setLevel(2);
s.reportCorrect();   // 连对 3 次自动升一档
s.reportWrong();     // 连错 2 次自动降一档

// 贴纸（优先发没拿过的，全齐了才重复发）
s.getStickers();              // ['g1', 'g3']
s.grantNewSticker();          // { sticker: {...}, isNew: true }

// 今日分钟（按日期存，跨天自动归零）
s.getTodayMinutes();  s.addTodayMinutes(3);
```

要点：
- **一定要加前缀**。不加的话两个游戏都用 `difficulty` 这个键会互相覆盖
- localStorage 全部包了 try/catch，隐私模式下会降级到内存（页面不崩）
- `get()` 遇到坏数据不抛错，退回原始字符串

## 设计原则（改游戏时请遵守）

1. **零文字化**：孩子不识字，引导靠图标 + `api.speak` 语音
2. **永不惩罚**：答错只用 `sound.soft()` + 温柔语音，不要叉、不要扣分、不要失败画面
3. **按钮要大**：3-6 岁点不准小目标，按钮尽量大
4. **答对才给奖励**：正反馈集中在 `api.reward()`
5. **区分「答错」和「正常玩法」**（新增，重要）
   只有「选错了目标」才算答错。
   翻牌配对里翻开两张不一样的牌、数数游戏里点了不认识的数字——
   这些是玩法的一部分，**不要调 `r.retry()`**，只出 `sound.soft()` 就行。
   否则孩子会因为「正常操作」被降难度。
6. **离屏即停**：玩家退出游戏后，别再往已卸载的 DOM 里塞东西。
   `api.rounds` 内部已经检查了 `isConnected`

## 运行方式

- **最简单**：双击 `index.html`
- **手机/平板**：把整个文件夹拷过去，用浏览器打开 index.html；或部署到任意静态服务器
- **注意**：浏览器要求「用户先点一下」才会出声，所以进页面后第一次触摸才会有语音，这是正常的
